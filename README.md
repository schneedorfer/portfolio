# Portfolio

Personal portfolio of Michal Schneedorfer — fullstack developer (React, Next.js, Node.js).

The content source of truth lives in [`docs/cv.md`](docs/cv.md) (extracted from `public/cv.pdf`).

## Stack

- [Next.js](https://nextjs.org) (App Router) + React
- [Tailwind CSS v4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) (Base UI primitives)
- TypeScript, pnpm

## Development

```bash
pnpm install
pnpm dev        # start dev server at http://localhost:3000
pnpm build      # production build
pnpm lint       # eslint
```
